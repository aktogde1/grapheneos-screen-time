Пока нет данных с телефона

Здесь нет примерной статистики: показатели и приложения появятся только после чтения вашего устройства.

  1. Установите Android Platform Tools на компьютере: команда adb должна быть доступна.
  2. На телефоне включите параметры разработчика и отладку по USB. Подключите телефон USB-кабелем с передачей данных.
  3. Разблокируйте телефон и подтвердите запрос «Разрешить отладку по USB» для этого компьютера.
  4. Запустите локальный сервер проекта и откройте выданный им адрес. Нажмите «Обновить данные».

Чтение через ADB не удаляет приложения и не меняет настройки. После сбора можно отключить отладку по USB. Короткая история на новом устройстве будет показана как есть, без заполнения выдуманными днями.

Как читать эти цифры и что здесь не учтено

Разблокированный экран — оценка времени, когда экран включён и блокировка скрыта. Включённый экран включает экран блокировки. Always-On Display и фоновая работа не входят в эти показатели. Разблокировки посчитаны по событиям скрытия экрана блокировки.

Время приложений приблизительно восстановлено по событиям активности. Музыка с выключенным экраном, VPN и фоновые сервисы не считаются экранной активностью приложения.

Категории — группировка, а не оценка Android; неизвестные приложения отображаются с именем пакета в категории «Прочее» (Other). Время приложений нельзя складывать для получения общего экранного времени: есть системные экраны и возможные перекрытия.

Последнее открытие — из более длинной истории. Ноль за период не означает «никогда не использовал». Само подключение кабеля обновление не запускает.
